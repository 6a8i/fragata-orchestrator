#### Register your XO instance

```
> fragata-cli register http://xo.my-company.net admin@admin.net admin
Successfully logged with admin@admin.net
```

Note: only a token will be saved in the configuration file.

#### List available objects

Prints all objects:

```
> fragata-cli list-objects
```

It is possible to filter on object properties, for instance to prints
all VM templates:

```
> fragata-cli list-objects type=VM-template
```

#### List available commands

```
> fragata-cli list-commands
```

Commands can be filtered using patterns:

```
> fragata-cli list-commands '{user,group}.*'
```

#### Execute a command

The same syntax is used for all commands: `fragata-cli <command> <param name>=<value>...`

E.g., adding a new server:

```
> fragata-cli server.add host=my.server.net username=root password=secret-password
42
```

The return value is the identifier of this new server in XO.

Because command lines are usually untyped, parameters (except `true` and `false` which are considered as
booleans) are assumed as strings by default, other types must be encoded as JSON and prefixed by `json:`:

```
> fragata-cli method string=foo number=json:42 array=json:'["item1", "item2"]'
```

##### Configuration export

```
> fragata-cli xo.exportConfig @=config.json
```

##### VM export

```
> fragata-cli vm.export vm=a01667e0-8e29-49fc-a550-17be4226783c @=vm.xva
```

##### XVA VM import

```
> fragata-cli vm.import sr=60a6939e-8b0a-4352-9954-5bde44bcdf7d @=vm.xva
```

> Note: `fragata-cli` only supports the import of XVA files. It will not import OVA files.

##### OVA VM import

A separate utility, [`fragata-upload-ova`](https://github.com/6a8i/fragata-fleet/blob/master/@fragata/upload-ova/README.md), can be used to import `.ova` files.
